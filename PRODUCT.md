# Product

## Register

product

## Platform

web

## Users

teams and knowledge workers who need a collaborative documentation platform

## Product Purpose

Make team knowledge discoverable, editable, and versioned — the single source of truth

## Brand Personality

collaborative, organized, modern

## Anti-references

- Generic SaaS templates with purple-to-blue gradients
- Over-designed dashboards where data is buried in decoration
- AI-generated interfaces that all share one look (Inter font, cream backgrounds, rounded everything)
- Enterprise apps that confuse density with professionalism

## Design Principles

- Write in Markdown, read in any format
- Every edit is a version — nothing is lost
- Search across all spaces, all pages, all comments
- Permission levels that match how teams actually collaborate

## Accessibility & Inclusion

- WCAG 2.1 Level AA compliance target
- Proper color contrast ratios (body text >= 4.5:1, large text >= 3:1)
- Keyboard navigable interface
- Screen reader friendly semantic HTML
- Support for prefers-reduced-motion and prefers-color-scheme
